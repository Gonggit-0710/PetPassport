# PawLog 사용 방법

PawLog 설명: **공이와 함께 한 시간들**. 공개 목록 `/blog/`와 각 글의 독립 주소로 구성합니다. 여행 외 일상도 같은 방법으로 작성합니다.

## 관리 화면 실행

저장소 폴더에서 다음 명령을 실행하고, 표시된 주소를 브라우저로 엽니다.

```powershell
python tools/blog_admin.py
```

관리 화면: http://127.0.0.1:8767/admin/

다음부터는 저장소의 `Start-PawLog.cmd`를 더블클릭해 실행해도 됩니다. 실행 창을 닫으면 관리 서버도 종료됩니다.

1. 새 이야기 또는 기존 글을 선택합니다.
2. 제목·주소·날짜·짧은 소개를 입력합니다. 기존 글의 주소는 보존합니다.
3. 사진 설명을 입력하고 사진을 업로드합니다. 대표 사진은 따로 선택하거나 제거할 수 있습니다. JPG·PNG·WebP, 파일당 10MB 이하입니다.
4. 본문을 작성합니다. 소제목·굵게·목록·링크를 지원합니다. 외부 문서 붙여넣기는 텍스트로 처리합니다.
5. 초안 저장 후 나중에 이어 쓰거나, 미리보기로 확인합니다.
6. 홈페이지에 게시를 누릅니다. 공개 글 파일·목록·검색·사이트맵이 이 PC에서 갱신됩니다.
7. GitHub Desktop에서 변경 파일을 확인하고 커밋한 뒤 **Push origin**을 누릅니다. GitHub Pages 배포 완료 후 운영 주소를 확인합니다.

게시 버튼은 인터넷 운영 사이트에 즉시 배포하는 버튼이 아닙니다. GitHub 인증·비밀번호·토큰은 관리 화면에 입력할 필요가 없습니다. 관리 화면은 이 PC에서만 열리며 공개 배포 파일에 포함되지 않습니다.

## 파일 위치

- `blog-content/posts/*.json`: 게시할 글 원본. 버전 관리합니다.
- `blog/media/`: 게시된 사진. 버전 관리합니다.
- `.blog-admin/drafts/`, `.blog-admin/uploads/`: 이 PC의 미게시 초안·사진. Git과 공개 배포에서 제외합니다. PC를 옮길 때 필요하면 별도 백업합니다.
- `blog-content/import-manifest.json`: 네이버 원문 링크와 가져온 사진 출처 기록.
- `tools/blog_core.py`: 공개 페이지 생성기. GitHub 배포에서도 실행됩니다.

원래 네이버 게시물·로컬 초안 폴더는 수정하지 않았습니다. 가져온 글은 네이버 게시본의 제목·본문·순서·이미지를 기준으로 합니다. 일부 네이버 링크 카드 디자인은 일반 링크로 표시합니다. 이후 네이버 글을 수정해도 자동 동기화되지 않으므로 PawLog에서도 수정해 주세요.
