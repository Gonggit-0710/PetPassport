# PawLog 작성·이전 가이드

2026-10-12 사용자 피드백을 반영한 기준입니다. PawLog 글을 신규 작성하거나 네이버 글을 이전·수정할 때 이 문서와 `AGENTS.md`를 먼저 확인합니다.

## 1. 이름과 운영 방식

- 메뉴 이름: **PawLog**.
- 설명: **공이와 함께, 여행도 일상도.** 여행뿐 아니라 일상도 담습니다.
- 정식 목록 주소는 `/pawlog/`, 글은 `/pawlog/{slug}/`, 사진은 `/pawlog/media/`입니다. 기존 `/blog/` 목록·글 주소는 새 주소로 이동하는 호환 페이지로 유지하고, 새 메뉴·검색·사이트맵·공유 링크에는 사용하지 않습니다.
- 사용자가 네이버 블로그에 글을 작성한 뒤 ChatGPT/Codex에게 해당 글의 PawLog 반영을 요청하는 방식을 기본으로 합니다.
- 네이버 블로그는 `https://blog.naver.com/pawtrip`입니다. 요청한 글 주소와 제공된 로컬 초안·사진을 함께 확인합니다.
- 자동 감시·자동 동기화는 설정되어 있지 않습니다. 네이버에 글을 올리기만 하면 홈페이지가 자동 변경되는 것은 아닙니다.
- 로컬 관리 화면은 선택 사항입니다. 사용자가 직접 편집할 필요 없이 AI에게 이전·수정을 요청할 수 있습니다.

## 2. 원본 확인과 내용 보존

- 공개 네이버 게시본의 제목·본문·사진 순서·캡션·대표 이미지·게시 날짜를 확인합니다. RSS의 요약만으로 본문을 만들지 않습니다.
- 로컬 초안과 사진은 `C:\Dev\PawTrip4u_Blog`에 있습니다. 원본 폴더를 보존하고 홈페이지용 파일을 별도로 만듭니다.
- 네이버 게시본을 본문 기준으로, 로컬 초안을 소제목 구조와 이미지로 된 안내·표의 원문 확인에 사용합니다. 차이가 있으면 임의로 문장을 섞거나 초안 전체로 덮어쓰지 않습니다.
- 개인 경험·숫자·날짜·말투·강조·공식 출처 링크를 그대로 보존합니다. 규정 최신화나 내용 보충은 별도 요청으로 처리합니다.
- 제목에 있던 줄바꿈을 한 줄로 바꿀 때 단어가 붙지 않도록 공백을 넣습니다. 예: `서류 총정리 6개월 전부터 준비한 이유`.
- 기존 글을 업데이트할 때는 글 주소(slug)를 유지하고, 같은 글을 새 주소로 중복 게시하지 않습니다.

## 3. 소제목과 본문 강조

- 글 제목은 h1, 실제 단락 제목은 h2, 그 아래 실제 하위 제목만 h3입니다.
- 네이버의 글자 크기나 굵기만 보고 소제목을 추정하지 않습니다. 초안의 h2/h3와 문맥을 대조합니다.
- 긴 본문 문장은 p로 표시합니다. 일부가 굵어도 소제목으로 바꾸지 않습니다. 강조는 strong/b만 사용하고 본문 크기를 유지합니다.
- 예: `귀국하는 날, 공항에서 터진 일`은 h2. `그 순간 머릿속에 떠오른 장면 하나…`는 p이며 서류 봉투 부분만 굵게 표시합니다.
- 현재 스타일 기준: 본문 17px, 소제목 h2는 PC 26px·모바일 24px, 하위 제목 h3는 21px. 본문 전체가 소제목보다 커지거나 굵어지지 않도록 확인합니다.
- 목록은 ul/ol/li로 작성하고, 안내 상자는 `div.note-box`를 사용합니다.

## 4. 사진과 대표 이미지

- 실제 여행 삽화·사진은 그대로 사용합니다. 얼굴·수트케이스 등 중요한 부분이 잘리지 않도록 전체 그림을 표시합니다.
- 대표 이미지는 첫 사진을 자동으로 고르지 않습니다. 네이버의 대표 이미지를 확인하고, 사용자가 지정한 장면을 우선합니다.
- 현재 확정된 대표 이미지:

| 글 | 대표 이미지 |
|---|---|
| 미국 호텔에 서류를 두고 온 글 | 공항에서 수트케이스를 열고 당황한 장면 (`gong-us-hotel-documents-3.jpg`) |
| 7kg·9kg 항공사 비교 글 | ‘이륙 후 다시 만난 공이는 바들바들 떨고 있었어요’ (`gong-cabin-airline-experience-4.png`) |
| 미국 여행 서류 준비 글 | 현재 병원 상담 장면 유지. 사용자가 별도 지정하면 변경 |
| 두 번째 미국행 글 | 네이버 대표 이미지인 ‘새벽 4시, 공이 혼자 한국 시간’ (`gong-second-us-trip-3.png`) |

- 대표 이미지를 바꾸면 목록 카드와 공유 미리보기(og:image)가 함께 바뀌는지 확인합니다. 본문 사진 순서는 별도로 유지합니다.
- 사진 파일은 홈페이지의 `pawlog/media/`에 보관합니다. 네이버 이미지 주소를 그대로 외부 연결하지 않습니다.
- 사진 설명을 alt와 캡션에 넣습니다. 의미 있는 캡션을 유지하고, 같은 설명을 불필요하게 두 번 반복하지 않습니다.

## 5. 스크린샷으로 된 글·표

- 안내문·체크리스트·표를 찍은 스크린샷을 작은 이미지로 그대로 붙이지 않습니다. 확대만으로 해결하려 하지 않습니다.
- 원본 초안의 문장을 찾아 실제 본문·목록·안내 상자로 옮깁니다. 표는 실제 HTML 표로 옮깁니다.
- 첫 글의 ‘그날 배운 것’은 초안의 세 가지 목록으로 표시합니다.
- 두 번째 글의 병원 상담·접종/검사·CDC 접수증·예약 전 확인 안내는 네 개의 안내 상자로, 서류 체크리스트는 실제 표로 표시합니다.
- 표는 작은 화면에서 내부 좌우 스크롤로 읽을 수 있게 하고 안내를 표시합니다. 페이지 전체가 옆으로 넘치면 안 됩니다.
- 텍스트로 대체한 스크린샷은 참조가 없는지 확인한 뒤 홈페이지 폴더와 배포 묶음에서 제거합니다. 원본 초안·네이버 자료는 삭제하지 않습니다.

## 6. 로고와 링크

- PawTrip 홈페이지와 PawLog에서는 기존 PawTrip 로고를 사용합니다. 텍스트 로고나 새 디자인으로 대체하지 않습니다. Games는 예외입니다.
- 현재 PawLog의 밝은 배경에는 `/media/logo-light.svg`를 사용합니다. 어두운 배경을 도입할 경우 `/media/logo-dark.svg`를 사용합니다.
- 글에 `네이버 원문 보기 ↗` 버튼을 표시하지 않습니다. 네이버 원문 주소는 내부 이전 기록에만 보관합니다.
- PawLog 목록·글 상단의 ‘네이버 블로그’ 탐색 링크도 표시하지 않습니다. 홈페이지에서 같은 글을 읽을 수 있으므로 PawLog와 My Dog 탐색만 유지합니다.
- 네이버 방문자를 홈페이지로 보내기 위한 글 하단 PawTrip 홍보 링크·링크 카드·빈 링크는 PawLog에서 제거합니다.
- 공통 글 하단의 My Dog 홍보 버튼도 추가하지 않습니다. 본문 속 PawTrip 언급은 문장 보존 원칙에 따라 유지합니다.
- 일반 사이트 탐색 메뉴, ‘다른 이야기 읽기’, 참고한 공식 자료 링크는 유지합니다.

## 7. 반영·검수·배포

1. 요청한 네이버 게시본과 로컬 초안을 확인합니다.
2. `blog-content/posts/*.json`을 새로 작성하거나 수정합니다. 사진은 `pawlog/media/`, 출처·대체 내역은 `blog-content/import-manifest.json`에 기록합니다.
3. 페이지 생성기로 목록·개별 글·검색·사이트맵을 갱신합니다. 생성된 HTML만 직접 고쳐 원본 JSON과 어긋나게 만들지 않습니다.
4. PC 1440px와 모바일 390·320px에서 제목/본문 크기, 사진 전체 표시, 대표 이미지, 작은 스크린샷 잔존 여부, 표 스크롤, 링크와 가로 넘침을 확인합니다.
5. 내용 변경이 없는 편집은 문장·숫자가 원본과 같은지 대조합니다. 삭제한 홍보 링크나 텍스트로 대체한 이미지 등 의도된 차이는 기록합니다.
6. 공개 파일 검사와 변경에 맞는 검증을 수행하고 `docs/HANDOFF.md`에 파일·이유·결과·남은 일을 기록합니다.
7. 먼저 로컬 미리보기를 제공합니다. 사용자 선택에 따라 GitHub Desktop에서 변경 내용을 커밋하고 **Push origin**으로 운영에 반영합니다. 로컬 저장·커밋·푸시·운영 배포를 구분해서 안내합니다.

## 8. 다음에 사용할 요청 문구

> 네이버 블로그에 새 글을 올렸어. [글 주소]를 PawLog 작성 가이드(`docs/PAWLOG-WRITING-GUIDE.md`)에 맞춰 홈페이지에 옮겨줘. 초안과 이미지는 `C:\Dev\PawTrip4u_Blog`에 있어. 대표 이미지는 [장면 설명]을 사용해줘. 로컬 미리보기와 배포 준비까지 해줘.

기존 글을 수정한 경우에는 ‘새 글’ 대신 ‘기존 글을 업데이트했어’라고 요청합니다. 대표 이미지를 바꾸지 않았다면 장면 설명은 생략해도 됩니다.
